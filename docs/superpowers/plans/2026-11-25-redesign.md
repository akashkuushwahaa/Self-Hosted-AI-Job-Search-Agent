# Redesign + Recruiter Home Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a recruiter-facing Home page at `/`, move search to `/jobs`, and give every page one simple, minimal, consistent look.

**Architecture:** Design tokens in `app/globals.css` (Tailwind v4 `@theme`), a small set of shared UI primitives in `app/ui.tsx`, and a client `Nav` for the active-link state. Pages swap their ad-hoc classes for these primitives; no data, query, auth or action logic changes.

**Tech Stack:** Next.js 16.4 (App Router), React 19.3, Tailwind 4.3, Geist font, Drizzle.

**Spec:** `docs/superpowers/specs/2026-11-25-redesign-design.md`

## Global Constraints

- No new dependencies.
- No changes to `lib/`, `db/`, server actions, or queries.
- Monochrome + Geist, one accent color; hairline borders, no shadows or gradients; dark mode kept.
- No personal details in the UI beyond the existing GitHub repo URL `https://github.com/akashkuushwahaa/Self-Hosted-AI-Job-Search-Agent`.
- Don't commit (another chat does commits). "Checkpoint" steps below run the checks only.
- Read `node_modules/next/dist/docs/` for any Next API you use that's not already in the codebase (per AGENTS.md).

## Review Focus

- Old links to `/?q=…` (bookmarks, README): `/` must redirect any request carrying `q` or `page` to `/jobs` with the same params.
- Home page in demo mode with PGlite: must call `connection()` before querying, like the other pages, or the prerender breaks the build.
- Home page when the DB is unreachable (non-demo, Postgres down): stats row should fall back to the static company count rather than crash the landing page.
- Phone width (375px): home hero, nav, and tracker board must not scroll horizontally; nav links wrap or scroll inside the header.
- Keyboard: every primitive keeps a visible focus ring (`focus-visible:`) in both themes.
